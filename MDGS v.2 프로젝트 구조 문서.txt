# MDGS 프로젝트 구조 문서

Modern Dark Game Store (MDGS) — Servlet/JSP 기반 게임 스토어 웹앱.
Eclipse Dynamic Web Project / Tomcat 10.1 / Jakarta EE 10 (`jakarta.servlet.*`) / Java 17 / Oracle DB.
Context root: `mdgs` → 접속 주소 `http://localhost:8888/mdgs/`

현재 구현된 기능은 **로그인 / 회원가입 / 로그아웃 / 게임 목록 열람**뿐입니다. 구매·리뷰·검색·게임 상세 페이지는 아직 구현되어 있지 않습니다 (7번 항목 참고).

## 2. HTML / CSS / 이미지 / JS는 어디에 있는가

이 프로젝트에는 순수 HTML 파일이 없습니다. 원래 정적 프로토타입이었던 `MDGS.html`/`MDGS.css`(별도 프로젝트 `3_Front/subject`에 존재)를 이 프로젝트로 옮기면서 전부 **JSP**로 전환했습니다.

| 종류 | 위치 | 비고 |
|---|---|---|
| 화면(옛 HTML) | `src/main/webapp/views/*.jsp` | 서블릿이 `forward`로만 진입 가능 (직접 URL 접근 대신 `/`, `/login`, `/register` 경유) |
| 공통 헤더/푸터 | `src/main/webapp/views/common/*.jsp` | `<jsp:include>`로 각 화면에 삽입됨 |
| CSS | `src/main/webapp/resources/css/mdgs.css` | 다크 테마, `:root`에 색상 변수 정의 |
| 이미지 | `src/main/webapp/resources/images/` | 게임 표지 6장 (파일명 공백은 전부 `_`로 치환됨) |
| JS | `src/main/webapp/resources/newFile.js` | 게임 카드 hover 시 우측 프리뷰 배경 교체 (바닐라 JS) |

JSP에서는 전부 `${pageContext.request.contextPath}/resources/...` 형태로 참조합니다 (예: `${pageContext.request.contextPath}/resources/css/mdgs.css`).

## 3. Java 소스 — 패키지별 역할

| 패키지 | 클래스 | 역할 |
|---|---|---|
| `config` | `DBConnection` | `DriverManager`로 Oracle 접속 (커넥션 풀 없이 매번 새 연결). URL/계정 정보 하드코딩. |
| `controller` | `GameListServlet` | `""`(홈)과 `/GameListServlet` 두 경로 모두 처리. `GameDAO.getAllGames()` 조회 후 `gameList.jsp`로 forward |
| `controller` | `LoginServlet` | `/login`. GET은 폼 표시, POST는 `UserDAO.login()` 검증 후 세션 생성 |
| `controller` | `LogoutServlet` | `/logout`. 세션 무효화 후 홈으로 redirect |
| `controller` | `RegisterServlet` | `/register`. GET은 폼 표시, POST는 중복 ID 체크 후 `UserDAO.register()` |
| `dao` | `UserDAO` | `USERS` 테이블 CRUD: `register`, `login`, `isDuplicateId` |
| `dao` | `GameDAO` | `getAllGames()` (사용 중), `purchaseGame`/`addReview` (작성은 되어 있으나 어떤 서블릿도 아직 호출하지 않음 — 구매/리뷰 미구현) |
| `model` | `User` | `USERS` 테이블 한 행에 대응하는 VO |
| `model` | `Game` | `GAMES` 테이블 한 행에 대응하는 VO (`imagePath` 포함) |
| `main` | `MainSystem` | Tomcat/서블릿과 무관한 콘솔 테스트 클래스. `main()`을 직접 실행해서 DAO 동작을 확인할 때만 사용 |

> `service` 패키지(빈 `UserService`/`GameService`)는 사용하지 않기로 결정하여 현재 프로젝트에 존재하지 않습니다. 서블릿이 DAO를 직접 호출하는 구조입니다.

## 4. URL 라우팅 표

| URL | 메서드 | 처리 서블릿 | 동작 |
|---|---|---|---|
| `/` | GET | `GameListServlet` | 게임 목록 조회 → `gameList.jsp` |
| `/GameListServlet` | GET | `GameListServlet` | 위와 동일 (기존 경로 유지) |
| `/login` | GET | `LoginServlet` | `login.jsp` 표시 |
| `/login` | POST | `LoginServlet` | 로그인 검증 → 성공 시 세션 생성 후 `/`로 이동, 실패 시 에러 메시지와 함께 `login.jsp` 재표시 |
| `/logout` | GET/POST | `LogoutServlet` | 세션 종료 후 `/`로 이동 |
| `/register` | GET | `RegisterServlet` | `register.jsp` 표시 |
| `/register` | POST | `RegisterServlet` | 중복 ID 체크 → 가입 처리 → 성공 시 `/login`으로 이동 |

**세션/요청 속성 이름 규칙**
- 세션: `loginId` (로그인한 아이디 문자열), `userSid` (User_SID, 현재는 저장만 하고 별도 사용처 없음)
- 요청: `errorMsg` (로그인/회원가입 실패 메시지), `gameList` (`List<Game>`, 게임 목록 화면용)

헤더(`views/common/header.jsp`)는 `sessionScope.loginId` 유무로 "로그인/회원가입" 링크와 "{아이디}님 | 로그아웃"을 조건부로 전환합니다.

## 5. 데이터베이스 스키마

Oracle, 계정 `C##MDGS` (SID: `xe`). 실제 스크립트는 `sql/schema.sql` 참고.

**USERS**
| 컬럼 | 타입 | 비고 |
|---|---|---|
| User_SID | VARCHAR2(30) | PK |
| ID | VARCHAR2(50) | UNIQUE, 로그인 아이디 |
| Password | VARCHAR2(100) | 평문 저장 (해싱 미적용) |
| Email | VARCHAR2(100) | |
| Age | NUMBER(3) | |
| Address | VARCHAR2(200) | |
| Card_Num | VARCHAR2(30) | |

**GAMES**
| 컬럼 | 타입 | 비고 |
|---|---|---|
| GAME_ID | NUMBER | PK |
| TITLE | VARCHAR2(200) | |
| GENRE | VARCHAR2(50) | 목록 화면 카테고리 표시에 사용 |
| PRICE | NUMBER(10,2) | |
| RELEASE_DATE | DATE | |
| DEVELOPER | VARCHAR2(100) | |
| IMAGE_PATH | VARCHAR2(200) | `resources/images/...` 형태 상대 경로. 이번 작업에서 추가한 컬럼 |

현재 시드 데이터: Hades / Rainbow Six Siege / Clair Obscur: Expedition 33 / Diablo IV (Game_ID 1~4).

**그 외 (존재하지만 미사용)**: `TRANSACTIONS`, `USER_LIBRARY`, `REVIEWS` 테이블이 이미 생성되어 있고 `GAMES`를 외래 키로 참조합니다. `GameDAO.purchaseGame()` / `addReview()`가 이 테이블들을 다루도록 작성되어는 있지만, 구매·리뷰 기능 자체가 아직 화면/서블릿에 연결되지 않아 실제로는 사용되지 않는 상태입니다.

## 6. 정적 프로토타입과의 관계

이 프로젝트가 시작되기 전 `c:\workspace\3_Front\subject\MDGS.html` / `MDGS.css`로 만들어졌던 정적 시안이 있습니다. 그 파일들의 디자인(다크 테마, 배너, 카테고리 메뉴, 게임 카드 그리드, 우측 프리뷰 패널)을 그대로 가져와 JSP로 재구성한 것이 지금의 `views/gameList.jsp` + `resources/css/mdgs.css`입니다. 원본과 다른 점:
- 게임 카드 4개가 하드코딩이 아니라 `<c:forEach>`로 DB 데이터를 순회하며 렌더링됨
- 카드 hover 시 우측 프리뷰 이미지를 바꾸던 CSS(`nth-child` 기반)는 게임 개수에 따라 깨지므로 제거하고, 자바스크립트(`newFile.js`)로 대체
- 로그인/회원가입 화면은 원본에 없던 것을 새로 추가 (`.auth-form-section` 스타일)

## 7. 구현 범위

**완료**: 로그인, 회원가입 (중복 ID 체크 포함), 로그아웃, 게임 목록 열람 (DB 연동, 이미지 포함), 로그인 상태에 따른 헤더 표시 전환

**미구현 (의도적으로 범위 제외)**: 게임 구매, 리뷰 작성, 검색 기능(헤더에 입력창은 있으나 비활성), 게임 상세 페이지(`views/gameDetail.jsp`는 빈 스텁으로 남아 있음), Service 계층
